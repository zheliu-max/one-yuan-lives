# 一块钱的两万种人生

> 同一笔钱，五种活法。你只走了其中一种。

一部手机竖屏的互动叙事作品：先认识你（学校 / 年级 / 专业 / 生活费），再让你看同一笔钱的五种去向——近期七年账本（按月）+ 长期三十年三线（按年），结尾生成纪念海报与 AI 回顾视频。

**在线体验**：https://zheliu-max.github.io/one-yuan-lives/

## 这是什么

用「故事」替代「说教」，用「代入感」替代「公式」：让每个大学生在几分钟里看清——自己每天随手花掉的那笔小钱，换到的是哪一种东西，以及三十年后它会变成什么。

## 八幕结构

| 幕 | 内容 |
|---|---|
| 封面 | 一块钱 / 两万种人生 / 五类去向 |
| 身份 | 年级、学校、专业大类、月生活费 |
| 第一笔钱 | 每天随手花掉的金额 + 能坚持存几年 |
| 岔路 | 喝掉 / 定投 / 买本书 |
| 时间机器 | 双模式：近期七年账本（按月） / 长期三十年三线（按年） |
| 反转 | 10,950 天 = 10,950 次选择 |
| 结局 | 三线对照：实际 / 理想 / 从未省，人性税 |
| 海报 | 纪念海报 + AI 回顾视频 |

## 五个口袋（互相转化）

| 口袋 | 买到什么 |
|---|---|
| 钱 | 更多的钱（定投 / 存款） |
| 能力 | 更强的自己（书 / 课 / 证 / 考研） |
| 经历 | 更厚的记忆（旅行 / 演唱会） |
| 关系 | 更广的关系（请客 / 家人 / 朋友） |
| 选择权 | 不必低头的余地（应急备用金） |

意外（丢手机、住院、诈骗、重修）按**真实概率**掷骰，此时口袋抵抗决定了曲线的断裂程度。

## 技术

纯静态页面：**零依赖、零构建、零网络请求**，断网也能完整演完。

```
demo/
  index.html   八幕结构与全部文案
  styles.css   纸张 / 暖光 / 宋体视觉语言
  app.js       身份、双模式账本、意外掷骰、三线、海报
  serve.mjs    本地预览服务器
  check.mjs    结构自检
```

本地预览：

```bash
node demo/serve.mjs     # http://127.0.0.1:4173/
node demo/check.mjs     # 结构自检
```

## 部署

推送到 `main` 后由 GitHub Actions 自动发布 `demo/` 到 GitHub Pages（见 `.github/workflows/pages.yml`）。

## 数据说明

复利按 `FV = P × (1+r)^n`（单笔）与 `FV = A × ((1+r)^n − 1) / r`（年金）计算；8% 是长期股票指数的历史假设，不是承诺，也未计入风险与税费。意外概率与生活成本为占位常量，最终版本将接入南京真实数据表（12306、携程、医保等）并标注来源与校准日期。

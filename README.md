# 一块钱的两万种人生

> 同一笔钱，五种活法。你只走了其中一种。

一部手机竖屏的互动叙事作品：先认识你（学校 / 年级 / 专业 / 生日 / 生活费），再让你一个月一个月地过完七年账本——每月决定这笔闲钱怎么放，特殊日子做取舍，最后把真实结果投射到三十年，生成纪念海报与 AI 回顾视频（预留位）。

**在线体验**：https://zheliu-max.github.io/one-yuan-lives/

## 这是什么

用「故事」替代「说教」，用「代入感」替代「公式」：让每个大学生在几分钟里看清——自己每天随手花掉的那笔小钱，换到的是哪一种东西，以及三十年后它会变成什么。

## 七幕结构

| 幕 | 内容 |
|---|---|
| 封面 | 一块钱 / 两万种人生 / 五类去向 |
| 身份 | 年级、学校（东南大学）、专业大类、生日月份、月生活费 |
| 第一笔钱 | 每天随手花掉的金额 + 能坚持存几年 |
| 时间机器 | 双模式：近期七年账本 / 长期三十年三线 |
| 反转 | 10,950 天 = 10,950 次选择 |
| 结局 | 三线对照：实际 / 理想 / 从未省，人性税 + 自动执行比例 |
| 海报 | 纪念海报 + AI 回顾视频（预留位） |

近期账本有两档节奏：**逐月**（每月都决定，大一默认）和**学年**（开学定方案 → 自动跑 → 只在大日子停下）。

## 五个口袋（互相转化）

| 口袋 | 买到什么 |
|---|---|
| 钱 | 更多的钱（定投 / 存款） |
| 能力 | 更强的自己（书 / 课 / 证 / 考研） |
| 经历 | 更厚的记忆（旅行 / 演唱会） |
| 关系 | 更广的关系（请客 / 家人 / 朋友） |
| 选择权 | 不必低头的余地（应急备用金） |

意外（丢手机、住院、诈骗、重修）按**真实概率**掷骰，此时口袋抵抗决定了曲线的断裂程度。

## 技术

纯静态页面：**零依赖、零构建、零网络请求**，断网也能完整演完。

```
docs/            作品本体（即 GitHub Pages 发布目录）
  index.html     七幕结构与全部文案
  styles.css     纸张 / 暖光 / 宋体 / 四季背景
  app.js         账本引擎、学年方案、意外、三线、海报、插画
  serve.mjs      本地预览服务器
  check.mjs      结构自检
plugins/
  git-autosave/  每回合结束自动提交（并可推送）的 DSH 插件
```

本地预览与自检：

```bash
node docs/serve.mjs     # http://127.0.0.1:4173/
node docs/check.mjs     # 结构自检
node plugins/git-autosave/test/e2e.mjs   # 插件端到端测试
```

## 自动保存（git-autosave）

`plugins/git-autosave` 装在桌面 profile 里，监听每个会话的 `turn/end`：任务一结束就在工作目录执行 `git add -A .`，有改动就提交；本仓库开启了 `push: true`，所以是**提交 + 推送**一条龙。

- 推送失败不会丢提交：本地照常保留，只写一条警告。
- 没有配置 remote 的仓库静默跳过。
- 提交标题取你最后一次真实请求，系统注入的上下文（时间戳、策略提示）会被自动跳过。
- 遵循 `.gitignore`，按工作目录划定提交范围，子代理的回合不单独提交。

配置与端到端测试见 `plugins/git-autosave/docs/DETAIL.md`。

## 部署

`docs/` 目录即发布内容，GitHub Pages 从 `main` 分支的 `/docs` 直接提供，无需构建。推送 `main` 后约 1 分钟自动更新。

# 一块钱的两万种人生 · 互动 demo（v2）

一部手机竖屏的互动叙事：先认识你（学校 / 年级 / 专业 / 生活费），再让你看同一笔钱五年种去向——近期七年账本（按月）+ 长期三十年三线（按年），结尾生成纪念海报与 AI 回顾视频。

纯静态页面：**零依赖、零构建、零网络请求**，断网也能完整演完。

## 怎么看

```
http://127.0.0.1:4173/
```

服务器没在跑时：

```powershell
node demo/serve.mjs
```

也可以直接双击 `demo/index.html`（file:// 打开同样能跑）。

## 八幕

| 屏 | 内容 | 交互 |
|---|---|---|
| 封面 | 一块钱 / 两万种人生 / 五类去向 | 走进这三十年 |
| 身份 | 年级、学校、专业大类、月生活费 | 四组 chips 单选 |
| 第一笔钱 | 每天随手花掉多少 + 能坚持存几年 | 数字 + 习惯 chips |
| 岔路 | 喝掉 / 定投 / 买本书 | 三选一 |
| 时间机器 | **双模式**：近期七年账本（按月） / 长期三十年三线（按年） | 拖时间轴、切换模式、掷骰重掷意外 |
| 反转 | 10,950 天 = 10,950 次选择，亮起来的是你选的那条 | 看完 |
| 结局 | 三线对照：实际 / 理想 / 从未省，人性税 | 看完 |
| 海报 | 纪念海报 + AI 回顾视频（预留位） | 保存 PNG / 生成视频 |

## 双模式设计

- **近期模式**（按月，0–84 月）：真实账本。生活费流入 → 基础支出 → 每日习惯投入（五口袋）。校历事件（开学教材、四六级、演唱会、双十一、压岁钱、考研班）+ **意外按真实概率掷骰**（丢手机约 6%/年、住院约 4%/年、诈骗约 5%/年、重修约 4%/年）。习惯衰减：设定"坚持 N 年"，超过后每月投入减半（人性税）。
- **长期模式**（按年，0–30 年）：把近期账本攒下的钱做种子，画三线——实际 / 理想（一直坚持）/ 从未省。理想与实际之差 = 人性税。
- **桥**：近期结算页算出七年五口袋，作为长期模式的种子。

## 五类去向（互相转化）

| 口袋 | 买到什么 | 典型 |
|---|---|---|
| 钱 | 更多的钱 | 定投 / 存款 |
| 能力 | 更强的自己 | 书 / 课 / 证 / 考研 |
| 经历 | 更厚的记忆 | 旅行 / 演唱会 |
| 关系 | 更广的关系 | 请客 / 家人 / 朋友 |
| 选择权 | 不必低头的余地 | 应急备用金 |

意外来临时，口袋不够就从现金补——这五次转化是被现实检验过的。

## 直达某一屏（演示用）

```
index.html#identity
index.html?choice=invest&mode=near&y=42#machine
index.html?choice=invest&mode=far&y=30#machine
index.html?choice=invest&mode=near&y=84#ending
index.html?choice=invest&mode=near&y=84#report
```

`choice` 取 `spend | invest | learn`；`mode` 取 `near | far`；`y` 近期是月份（0–84）、长期是年份（0–30）；`#` 后面是屏名。长期屏会先自动补跑近期账本做种子。

## 自检

```powershell
node demo/check.mjs
```

检查文件齐全、`app.js` 引用的 id 都存在、class 都有样式、八屏顺序与 `SCREENS` 一致、复利公式与方案数字对齐、无外部地址（离线可用）。

## 预留位（接 AI 的地方）

- **AI 实时生成**：`narrationNear()` / `narrationFar()` / `cardQuote()` 就是文案接口——把固定句子换成调模型按身份、金额、选择生成，断网用当前模板兜底。
- **AI 回顾视频**：`generateVideo()` 已写好流程（按钮 → 模拟生成 → 插入 video 占位），把 `src` 换成服务返回的 mp4 即可。
- **AI 分镜图**：内联 SVG 换成 AI 插画时，替换 `.scene-*` 并保留 `data-year` 阈值逻辑。
- **南京真实数据**：校历事件与意外概率目前是占位常量，最终接入 `data/` 校准表（12306、携程、景区学生票等，全部标来源与校准日期）。

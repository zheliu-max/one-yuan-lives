# 一块钱的两万种人生 · 互动 demo

一部手机竖屏的互动叙事：你随手花掉一笔小钱，把它放进一台时间机器，看三十年后它变成了什么——最后发现，真正被复利的是「每天」，而不是那十五块。

纯静态页面：**零依赖、零构建、零网络请求**，断网也能完整演完。

## 怎么看

线上预览（本机静态服务器，改完刷新就是最新）：

```
http://127.0.0.1:4173/
```

服务器没在跑时，一条命令拉起来：

```powershell
node demo/serve.mjs
```

也可以直接双击 `demo/index.html`（file:// 打开同样能跑，只是没有自动刷新）。

## 三个「经得起追问」的设计

**1. 「两万」不是修辞，是次数。**
30 年 × 365 天 × 每天约两次「这钱花不花」的岔路 ≈ 21,900 次。反转那一屏的两万个点，就是这个数字的视觉化：你只走了其中一条。

**2. 62 万不是一个数，而是两条口径。**
默认「每天都算」，切到「只算这一杯」会掉到 151 元——这一步是故意留的，评委追问「你这 62 万是不是偷换概念」时，把开关一拨就是回答。

| 口径 | 公式 | 30 年 · 8% |
|---|---|---|
| 只算这一杯（单笔） | `FV = P × (1+r)^n` | 15 元 → 151 元 |
| 每天都算（年金） | `FV = A × ((1+r)^n − 1) / r` | 每天 15 元 → 约 62.0 万 |
| 扣除 3% 通胀 | `FV / (1+i)^n` | 约 25.6 万（今天的购买力） |

年化 3% / 5% / 8% 可选，页面底部固定标注：8% 是长期股票指数的历史假设，不是承诺，也未计入风险与税费。

**3. 第三条路故意不算钱。**
选「买本书」时读数变成「不可计算」，并且明说这一屏不给数字——把「知识回报无法定价」写进作品，比硬编一个数字更站得住。

## 目录

```
demo/
  index.html   六幕结构与全部文案
  styles.css   纸张 / 暖光 / 宋体的视觉语言
  app.js       复利计算、时间轴、星图、报告卡绘制
  serve.mjs    零依赖静态服务器（预览用）
  check.mjs    结构自检：资源、id 契约、公式、离线性
  README.md
```

## 自检

```powershell
node demo/check.mjs
```

检查文件齐全、`app.js` 引用的每个 id 都存在、页面的 class 都有样式、六屏顺序与 `SCREENS` 一致、复利公式结果与方案里的数字对齐、以及没有任何外部地址（保证离线）。

## 直达某一屏（演示用）

```
index.html#machine?choice=invest&y=22
index.html?choice=spend&y=30#machine
index.html?choice=learn&y=18#report
```

`choice` 取 `spend | invest | learn`，`y` 是年份（0–30），`#` 后面是屏名。评审现场可以直接跳到你想要的那一幕。

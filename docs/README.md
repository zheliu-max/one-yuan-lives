# 一块钱的两万种人生 · 互动 demo（v2）

一部手机竖屏的互动叙事：先认识你（学校 / 年级 / 专业 / 生活费），再让你看同一笔钱五种去向——近期七年账本（按月）+ 长期三十年三线（按年），结尾生成纪念海报与 AI 回顾视频。

纯静态页面：**零依赖、零构建、零网络请求**，断网也能完整演完。

## 视觉：季节随月份变化 + 每个日子一张插画

- **四季背景**：账本走到 3–5 月是春天（青绿）、6–8 月夏天（暖黄）、9–11 月秋天（琥珀）、12–2 月冬天（冷灰），整页背景随月份平滑过渡。
- **每个特殊日子一张内联 SVG 插画**：寒假小屋与火车、春节红包灯笼、生日蛋糕、考试卷与时钟、演唱会光束、栖霞山枫叶、期末台灯、毕业学士帽、行李箱与机票、实习工牌、开学教学楼、双十一购物车、跨年烟花、考研书堆。全部内联，离线可播。

## 事件不是一张表，是生成器

同一个"演唱会"，每次的歌手、票价、抢不抢得到都不一样；同一个"生日"，主角不同、你的应对不同、后续关系也不同。

| 事件 | 现在怎么生成 |
|---|---|
| **演唱会** | 从歌手池随机（周杰伦/陈奕迅/五月天/薛之谦/本地乐队/校园歌手），每个歌手有热度值决定抢票成功率；票价分内场/看台/山顶三档 → **抢票失败会售罄** → 可选择**找黄牛加价 300**（15% 概率假票） |
| **暑假旅行** | 先选**同行者**（一个人 / 室友 / 社团朋友，影响花费与相遇概率），再从 7 个目的地里选（扬州 400 / 黄山 800 / 青岛 1200 / 西安 1600 / 成都 1900 / 三亚 2400 / 哪也不去）；**一个人去有 16% 概率遇见喜欢的人** |
| **朋友生日** | 4 个朋友各有生日月份（小林 3 月、阿哲 10 月、张姐 12 月、老周 6 月）；选项：请吃饭 200 / 送礼 150 / 发红包 66 / 装不知道 → 影响**关系值** |
| **关系值** | 记账本「身边的人」里，会随你的每次表态变化；决定谁跟你更近 |
| **恋爱线** | 旅行中遇见阿青后进入恋爱状态，记在关系里，并进入回放与海报 |

事件按 `(年, 月, 生日)` 确定性生成并缓存，所以**回看、回放、结算时结果不会乱变**。

## 近期模式：每个月问一次

这是作品的核心循环，不是自动播放：

```
第 N 个月（从九月开学起算）
  ↓
生活费到账 → 固定支出 → 这个月能决定的闲钱
  ↓
【决策】这笔闲钱放哪里？（五选一）
   💰 存起来   📚 买书/报课   🎒 攒旅行基金   🍲 请客/顾家   🛟 留作应急
  ↓
【特殊日子】（如果这个月有）花 / 不花
   生日 · 春节压岁钱 · 双十一 · 五一 · 国庆秋游 · 四六级 · 期末
   毕业季 · 考研班 · 暑假旅行（南京出发真实价格）
  ↓
本月账本结算 → 下一个月
```

- **84 次决策**（逐月模式）：七年 × 12 个月，每个月的闲钱都由玩家分配。
- **特殊日子**：生日按玩家选的月份触发；暑假给 5 个真实目的地，价格构成写在选项里。
- **快进**：没时间的玩家可以一键走完，但账本会如实记录"你没有选"。
- **可回看**：拖动时间轴能回到任意一个月，重来这一个月会撤销该月决策。

## 两档节奏：逐月 vs 学年（解决"84 次太累"）

84 个月如果每个月都问一遍，操作量太大；但只有按月才真实。折中方案是**换掉决策的层级**：

| 节奏 | 体验 | 交互次数 |
|---|---|---|
| **逐月** | 每个月都问"这笔闲钱怎么放" | 84 次 |
| **学年** | 开学定一次方案 → 自动跑 → 只在**大日子**停下 | 约 7 次方案 + 约 10 次大日子 |

- **第一年默认逐月**（教学：让你先学会这件事），**大二起自动切学年模式**，随时可以切回来。
- **大日子**（会打断你）：生日、演唱会、毕业季、暑假旅行。
- **小日子**（按你的方案自动决定）：开学采购、四六级、双十一、秋游、跨年、考研报名、清明踏青、寒假回家——花不花，取决于你的方案里给那个口袋留了多少。
- **学年结束**给一张结算卡：这一年你亲手决定了几个月、自动跑了几个月、去过哪、花了几次、放过了几次。
- **结局**会告诉你：七年里有多少个月是"按方案自动走的"。

## 双模式设计

- **近期模式**（按月，0–84 月）：真实账本。生活费流入 → 基础支出 → 每日习惯投入（五口袋）。校历事件（开学教材、四六级、演唱会、双十一、压岁钱、考研班）+ **意外按真实概率掷骰**（丢手机约 6%/年、住院约 4%/年、诈骗约 5%/年、重修约 4%/年）。习惯衰减：设定"坚持 N 年"，超过后每月投入减半（人性税）。
- **长期模式**（按年，0–30 年）：把近期账本攒下的钱做种子，画三线——实际 / 理想（一直坚持）/ 从未省。理想与实际之差 = 人性税。
- **桥**：近期结算页算出七年五口袋，作为长期模式的种子。

## 五类去向（互相转化）

| 口袋 | 买到什么 | 典型 |
|---|---|---|
| 钱 | 更多的钱 | 定投 / 存款 |
| 能力 | 更强的自己 | 书 / 课 / 证 / 考研 |
| 经历 | 更厚的记忆 | 旅行 / 演唱会 |
| 关系 | 更广的关系 | 请客 / 家人 / 朋友 |
| 选择权 | 不必低头的余地 | 应急备用金 |

意外来临时，口袋不够就从现金补——这五次转化是被现实检验过的。

## 预留位（接 AI 的地方）

- **AI 实时生成**：`narrationNear()` / `narrationFar()` / `cardQuote()` 就是文案接口——把固定句子换成调模型按身份、金额、选择生成，断网用当前模板兜底。
- **AI 回顾视频**：`generateVideo()` 已写好流程（按钮 → 模拟生成 → 插入 video 占位），把 `src` 换成服务返回的 mp4 即可。
- **AI 分镜图**：内联 SVG 换成 AI 插画时，替换 `.scene-*` 并保留 `data-year` 阈值逻辑。
- **南京真实数据**：校历事件与意外概率目前是占位常量，最终接入 `data/` 校准表（12306、携程、景区学生票等，全部标来源与校准日期）。

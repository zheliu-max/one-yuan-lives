# 一块钱的两万种人生 · 互动 demo（v2）

一部手机竖屏的互动叙事：先认识你（学校 / 年级 / 专业 / 生活费），再让你看同一笔钱五种去向——近期七年账本（按月）+ 长期三十年三线（按年），结尾生成纪念海报与 AI 回顾视频。

纯静态页面：**零依赖、零构建、零网络请求**，断网也能完整演完。

## 生活建档：第一个月不再"被扣一个固定数"

原来每个月的固定支出是 `生活费 × 0.55` —— 一个凭空系数。现在改成**先在开学第一周过一遍日子**，把你选出来的花法沉淀成档案：

| 场景 | 你选的 |
|---|---|
| 第 1 天 · 早上 | 食堂 4 / 路上买 5 / 外卖 8（元/天） |
| 第 3 天 · 中午 | 食堂 12 / 混着 18 / 外卖 25 |
| 第 5 天 · 晚上 | 食堂 10 / 小炒 15 / 夜宵外卖 22 |
| 第 6 天 · 出门 | 单车月卡 15 / 地铁 60 / 经常打车 150（元/月） |
| 第 7 天 · 周末 | 很少出去 50 / 偶尔聚聚 100 / 局挺多 200 |

固定项：日用 80 + 校园套餐 39。

选完立刻给一张**开销档案**：

```
餐费（早 4 / 午 12 / 晚 10 元）   780 元
交通                              15 元
日用 + 通讯                      119 元
社交                              50 元
每月固定支出                     964 元
生活费 1,800 扣完还剩           +836 元
按这个过法，四年能攒下约 4.0 万。
```

- 之后每个月按这份档案扣，并允许 **±8% 的真实波动**（按月确定性生成，回看不会乱跳）。
- 同样的 1,800 生活费，最省 vs 最松，四年能差出 2 万以上——这个对比是玩家自己选出来的。
- 账本抽屉里能随时查看档案明细，固定支出现在可以追溯。
- 收入明细里「固定支出」和「每天省下的」分成两行，不再混在一起。

## 意外：按场景触发，真实概率

意外**不是每月抽签**，也不是"每年一次抽是哪个"。它挂在具体场景上：到了该发生的时刻，按真实概率判定这一次会不会发生。

| 意外 | 触发场景 | 年化概率 | 单次概率 | 数据来源 |
|---|---|---|---|---|
| 挂科重修 | 期末（每年 2 次） | 6.9% | 3.5% | 约 25% 本科生有重修经历，四年折算 |
| 电信诈骗 | 开学季 / 兼职 / 二手交易 / 买票（4 次） | 5.8% | 1.5% | 广州大学城 1000 份样本：过去一年被骗 5.8% |
| 手机被偷 | 旅行 / 演唱会 / 火车站 / 开学报到（5 次） | 5.0% | 1.0% | 超六成用户累计丢过手机，取近年低值 |
| 生病住院 | 换季（11–1 月、3 月，3 次） | 2.0% | 0.7% | 大学生医保平台两年住院率 0.8%；20–29 岁住院率 7%，取学生低值 |

单次概率由年化反推：`p = 1 − (1 − 年化)^(1/机会点)`。

**七年内至少遇到一次**：挂科 39% / 诈骗 34% / 手机 30% / 住院 13%，合计约 **76%**。封面有一张概率图说明这件事。

### 意外是"第二幕"

先演当月的事件（演唱会、旅行、期末），事件处理完之后才可能触发意外——因为意外需要一个场景。

```
第一幕：演唱会 → 你选了内场
第二幕：⚠️ 散场人潮里，手机被偷了
        [ 买台新的 2,500 ] [ 买台二手的 1,200 ] [ 借室友旧手机 0 · 关系 −1.5 ]
```

- **每个选项都能拒绝**：最后一档通常是 0 元硬扛，代价转移到关系、身体或毕业延期上。
- 意外花掉的钱**计入当月闲钱扣除**——处理完才看得到还剩多少。
- 意外卡没处理完之前，"分配闲钱"是锁住的。
- 结果按 `(月份, 生日)` 确定性生成，回看/回放不会变。

## 事件不是一张表，是生成器

同一个"演唱会"，每次的歌手、票价、抢不抢得到都不一样；同一个"生日"，主角不同、你的应对不同、后续关系也不同。

| 事件 | 现在怎么生成 |
|---|---|
| **演唱会** | 从歌手池随机（周杰伦/陈奕迅/五月天/薛之谦/本地乐队/校园歌手），每个歌手有热度值决定抢票成功率；票价分内场/看台/山顶三档 → **抢票失败会售罄** → 可选择**找黄牛加价 300**（15% 概率假票） |
| **暑假旅行** | 先选**同行者**（一个人 / 室友 / 社团朋友，影响花费与相遇概率），再从 7 个目的地里选（扬州 400 / 黄山 800 / 青岛 1200 / 西安 1600 / 成都 1900 / 三亚 2400 / 哪也不去）；**一个人去有 16% 概率遇见喜欢的人** |
| **朋友生日** | 4 个朋友各有生日月份（小林 3 月、阿哲 10 月、张姐 12 月、老周 6 月）；选项：请吃饭 200 / 送礼 150 / 发红包 66 / 装不知道 → 影响**关系值** |
| **关系值** | 记账本「身边的人」里，会随你的每次表态变化；决定谁跟你更近 |
| **恋爱线** | 旅行中遇见阿青后进入恋爱状态，记在关系里，并进入回放与海报 |

事件按 `(年, 月, 生日)` 确定性生成并缓存，所以**回看、回放、结算时结果不会乱变**。

## 换挡：这个月存少了，要不要下个月省一点

以**第一个月存下的钱**为基准。后面的月份如果存得更少（通常是因为这个月有笔大开销），会问你：

> 第一个月你能存下 410 元，这个月只剩 100 元（少了 310 元）。
> **要不要下个月降一档？**
>
> 规则：降档只影响下一个月，再下个月自动调回原档；累计降档超过 3 次后不再调回。

- **降一档** = 在现有档案基础上：每顿饭再省一点、交通改单车、社交减半（不低于最省下限）。固定支出会明显下降，当月能存的钱回升。
- **只降一个月**：再下个月自动回到你原来的档案——这是"临时勒紧腰带"，不是长期改变生活。
- **累计超过 3 次**：从第 4 次起不再调回，一直是降档状态（人一旦习惯了省，就回不去了）。
- **已经是最省一档的人**不会收到提示（降无可降）。
- 降档进行中的月份，主屏会显示「这个月降档中：食堂 + 单车 + 少出去，固定支出降到 964 元」。

## 近期模式：每个月问一次

这是作品的核心循环，不是自动播放：

```
第 N 个月（从九月开学起算）
  ↓
生活费到账 → 按生活档案扣固定支出 → 这个月的现金
  ↓
【事件】如果这个月有事（演唱会 / 旅行 / 生日 / 双十一…）
   先处理它 —— 花掉的钱直接从现金里付
   处理完之前，"分配"是锁住的
  ↓
【决策】剩下的才是闲钱：放哪里？（五选一）
   💰 存起来   📚 买书/报课   🎒 攒旅行基金   🍲 请客/顾家   🛟 留作应急
  ↓
本月账本结算 → 下一个月
```

- **顺序是"先经历、再分配"**：事件花掉多少，当月能存的就少多少，界面上会明说"这件事花掉 66 元，这个月还剩 334 可以分配"。
- **钱不够就会超支**：事件花费超过当月现金时，优先动用手边口袋（应急 → 经历 → 关系 → 能力 → 钱袋），还不够就记为负现金。
- **84 次决策**（逐月模式）：七年 × 12 个月，每个月的闲钱都由玩家分配。
- **快进**：没时间的玩家可以一键走完，但账本会如实记录"你没有选"。
- **可回看**：拖动时间轴能回到任意一个月，重来这一个月会撤销该月决策。

## 两档节奏：逐月 vs 学年（解决"84 次太累"）

84 个月如果每个月都问一遍，操作量太大；但只有按月才真实。折中方案是**换掉决策的层级**：

| 节奏 | 体验 | 交互次数 |
|---|---|---|
| **逐月** | 每个月都问"这笔闲钱怎么放" | 84 次 |
| **学年** | 开学定一次方案 → 自动跑 → 只在**大日子**停下 | 约 7 次方案 + 约 10 次大日子 |

- **第一年默认逐月**（教学：让你先学会这件事），**大二起自动切学年模式**，随时可以切回来。
- **大日子**（会打断你）：生日、演唱会、毕业季、暑假旅行。
- **小日子**（按你的方案自动决定）：开学采购、四六级、双十一、秋游、跨年、考研报名、清明踏青、寒假回家——花不花，取决于你的方案里给那个口袋留了多少。
- **学年结束**给一张结算卡：这一年你亲手决定了几个月、自动跑了几个月、去过哪、花了几次、放过了几次。
- **结局**会告诉你：七年里有多少个月是"按方案自动走的"。

## 双模式设计

- **近期模式**（按月，0–84 月）：真实账本。生活费流入 → 基础支出 → 每日习惯投入（五口袋）。校历事件（开学教材、四六级、演唱会、双十一、压岁钱、考研班）+ **意外按真实概率掷骰**（丢手机约 6%/年、住院约 4%/年、诈骗约 5%/年、重修约 4%/年）。习惯衰减：设定"坚持 N 年"，超过后每月投入减半（人性税）。
- **长期模式**（按年，0–30 年）：把近期账本攒下的钱做种子，画三线——实际 / 理想（一直坚持）/ 从未省。理想与实际之差 = 人性税。
- **桥**：近期结算页算出七年五口袋，作为长期模式的种子。

## 五类去向（互相转化）

| 口袋 | 买到什么 | 典型 |
|---|---|---|
| 钱 | 更多的钱 | 定投 / 存款 |
| 能力 | 更强的自己 | 书 / 课 / 证 / 考研 |
| 经历 | 更厚的记忆 | 旅行 / 演唱会 |
| 关系 | 更广的关系 | 请客 / 家人 / 朋友 |
| 选择权 | 不必低头的余地 | 应急备用金 |

意外来临时，口袋不够就从现金补——这五次转化是被现实检验过的。
